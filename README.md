# claude-dino

Игра про динозаврика (как в Chrome без интернета) прямо над строкой ввода Claude Code.
Играть можно, пока Claude работает; когда он заканчивает ответ, игра сама встаёт на паузу и
пишет «● Claude закончил». Токены не расходуются: команда и игра отвечают сами, модель не вызывается.

Это мод Claude Code на **function hooks** (ранний доступ): TypeScript, который выполняется внутри
процесса Claude Code. API может меняться между релизами.

## Что нужно

- Claude Code 2.1.269 или новее и переменная `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`.
- Запуск в терминале (`claude`). В панели VSCode, десктопном и мобильном приложении игра не рисуется.
- **Полноэкранный режим Claude Code: `/tui fullscreen`.** Клавиатуру игре даёт клик по полю, а клики
  Claude Code видит только в полноэкранном режиме. В обычном режиме игра откроется и сама об этом скажет.

## Установка

1. В `~/.claude/settings.json` добавить (или слить с существующим ключом `env`):

   ```json
   { "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }
   ```

2. Поставить плагин из папки — она сама себе marketplace:

   ```sh
   claude plugin marketplace add /путь/к/claude-dino
   claude plugin install claude-dino@claude-dino
   ```

   Без установки, на один запуск: `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude --plugin-dir /путь/к/claude-dino`.

## Как играть

`/dino` открывает и закрывает игру, `/dino best` показывает рекорд.

1. Кликните по полю — игра получает клавиатуру и стартует. **Esc** возвращает клавиатуру строке ввода.
2. **Пробел**, **↑**, `w`, Enter или клик — прыжок.
3. **↓** или `s` — пригнуться (под птицей на средней высоте); в воздухе — быстрое падение.
   Терминал не сообщает, что клавишу отпустили, поэтому нажатие пригибает на 0,6 с, а удержание продлевает.
4. `p` — пауза. Снятие с паузы (`p`, пробел или клик) запускает **обратный отсчёт 3 секунды**;
   `p` во время отсчёта возвращает на паузу.
5. `r` — начать заново.

Клавиши работают и в русской раскладке (`з` = `p`, `к` = `r`, `ц` = `w`, `ы` = `s`).
Скорость растёт с очками; птицы появляются со 150 очков. Рекорд хранится в хранилище плагина на этой машине.

## Устройство

- `hooks/game/dino.ts` — вся игра как чистые функции: физика, препятствия, столкновения, режимы
  (`ready → running ⇄ paused → countdown → running`, `over`). Ничего не знает о Claude Code.
  `advance()` переводит реальное время в шаги логики по 50 мс: кадры терминала приходят ~16 раз в
  секунду и неровно, а отсчёт обязан длиться 3 секунды по часам.
- `hooks/game/sprites.ts` — спрайты и сборка кадра в строки текста, тоже чистые функции.
- `hooks/dino.tsx` — поверхность (`Client`): таймер кадров, клавиши, мышь, вывод.
- `hooks/register.tsx` — хуки: команда `/dino`, рекорд в `$.store`, сигнал «Claude закончил».

## Разработка

```sh
npm test             # логика и кадры: node --test, без зависимостей (нужен node 24+)
npm run test:hooks   # хуки и поверхность в окружении движка: claude plugin test
npm run typecheck    # tsc; типы API кладёт /plugin-types в .claude/types
npm run preview      # характерные кадры в консоль, без Claude Code
```

В тесте логики есть бот: он проходит игру до потолка скорости на 15 сочетаниях ширины поля и
зерна случайности — так проверяется, что физика прыжка, размеры препятствий и зазоры проходимы.
