# claude-dino

Игра про динозаврика (как в Chrome без интернета) прямо над строкой ввода Claude Code.
Играть можно, пока Claude работает; когда он заканчивает ответ, игра сама встаёт на паузу и
пишет «● Claude закончил». Токены не расходуются: команда и игра отвечают сами, модель не вызывается.

Это мод Claude Code на **function hooks** (ранний доступ): TypeScript, который выполняется внутри
процесса Claude Code. API может меняться между релизами.

## Что нужно

- Claude Code 2.1.269 или новее и переменная `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1`.
- Запуск в терминале (`claude`). В панели VSCode, десктопном и мобильном приложении игра не рисуется.
- **Полноэкранный режим Claude Code: `/tui fullscreen`.** Клавиатуру игре даёт клик по полю, а клики
  Claude Code видит только в полноэкранном режиме. В обычном режиме игра откроется и сама об этом скажет.

- **Высокое окно терминала.** Полосе над строкой ввода движок отдаёт примерно половину высоты
  терминала минус 6 строк, поэтому:

  | Высота терминала | Что получится |
  |---|---|
  | от 42 строк | крупный динозавр 10×7 клеток, полоса 15 строк |
  | 34–41 | компактный 7×4, полоса 11 строк |
  | 28–33 | компактный без строки подсказки; в самом низком окне верх прыжка срезается |
  | меньше 28 | игра не открывается и пишет, что окно нужно растянуть |

  Размер выбирается на раунд: растянули окно — следующий раунд пойдёт крупным.

## Установка

1. **Включить function hooks.** В `~/.claude/settings.json` добавить (или слить с существующим
   ключом `env`):

   ```json
   { "env": { "CLAUDE_CODE_ENABLE_FUNCTION_HOOKS": "1" } }
   ```

   Это включает модули хуков у **всех** установленных плагинов, а не только у этого. Без
   переменной плагин поставится, но команды `/dino` не будет.

2. **Поставить плагин из папки** — она сама себе marketplace:

   ```sh
   claude plugin marketplace add /путь/к/claude-dino
   claude plugin install claude-dino@claude-dino
   ```

3. **Проверить.** `claude plugin list` должен показать `claude-dino@claude-dino … enabled`.
   Перезапустить `claude` в терминале, выполнить `/tui fullscreen`, затем `/dino`.

Без установки, на один запуск (так же удобно разрабатывать — файлы подхватываются с диска):

```sh
CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1 claude --plugin-dir /путь/к/claude-dino
```

### Обновление

Установленный плагин — это копия в `~/.claude/plugins/cache/`, правки в папке проекта в неё сами
не попадают. Менеджер плагинов сравнивает **номер версии**: без его смены обновления не будет
(«already at the latest version»).

```sh
# 1. поднять "version" в .claude-plugin/plugin.json
claude plugin marketplace update claude-dino
claude plugin update claude-dino@claude-dino
# 2. перезапустить claude
```

Рекорд у установленного плагина и у запущенного через `--plugin-dir` хранится раздельно.

### Удаление

```sh
claude plugin uninstall claude-dino@claude-dino
claude plugin marketplace remove claude-dino
```

Переменную `CLAUDE_CODE_ENABLE_FUNCTION_HOOKS` убирайте из настроек, только если других модов нет.

### Если не работает

- **`/dino` — неизвестная команда.** Не включены function hooks (шаг 1) или плагин не загружен
  (`claude plugin list`). Причину отказа загрузки движок пишет тусклой строкой в транскрипте и
  подробно — в лог: `claude --debug-file /tmp/dino.log`, искать `claude-dino`.
- **На поле «НУЖНА МЫШЬ».** Claude Code в обычном режиме: выполните `/tui fullscreen` и откройте `/dino` снова.
- **Клавиши уходят в строку ввода.** Сначала кликните по полю. Esc возвращает клавиатуру строке ввода.
- **Клик не срабатывает.** Терминал не сообщает о мыши приложению (в tmux за это обычно отвечает `set -g mouse on`).
- **Вместо игры строка «окно низковато».** Растяните окно терминала — см. таблицу выше.
- **Между строками спрайта видны полоски.** Это межстрочный интервал терминала; ставится в 1.0 в его настройках.

## Как играть

`/dino` открывает и закрывает игру, `/dino best` показывает рекорд.

1. Кликните по полю — игра получает клавиатуру и стартует. **Esc** возвращает клавиатуру строке ввода.
2. **Пробел**, **↑**, `w`, Enter или клик — прыжок.
3. **↓** или `s` — пригнуться (под птицей на средней высоте); в воздухе — быстрое падение.
   Терминал не сообщает, что клавишу отпустили, поэтому нажатие пригибает на 0,6 с, а удержание продлевает.
4. `p` — пауза. Снятие с паузы (`p`, пробел или клик) запускает **обратный отсчёт 3 секунды**;
   `p` во время отсчёта возвращает на паузу.
5. `r` — начать заново.

Клавиши работают и в русской раскладке (`з` = `p`, `к` = `r`, `ц` = `w`, `ы` = `s`).
Скорость растёт с очками; птицы появляются со 150 очков. Рекорд хранится в хранилище плагина на этой машине.

## Устройство

- `hooks/game/dino.ts` — вся игра как чистые функции: физика, препятствия, столкновения, режимы
  (`ready → running ⇄ paused → countdown → running`, `over`). Ничего не знает о Claude Code.
  `advance()` переводит реальное время в шаги логики по 50 мс: кадры терминала приходят ~16 раз в
  секунду и неровно, а отсчёт обязан длиться 3 секунды по часам.
  Всё, что зависит от величины спрайтов (рост, хитбокс, высота прыжка, скорости, размеры
  кактусов и птиц), собрано в наборах `COMPACT` и `LARGE` типа `Metrics`: новый размер или
  персонаж — это данные, а не правка логики.
- `hooks/game/sprites.ts` — спрайты и сборка кадра в строки текста, тоже чистые функции.
  Спрайты хранятся **битовыми картами** (`#` — пиксель) и переводятся в символы-четвертинки
  клетки (`▘▝▖▗▀▄▌▐█`, 2×2 пикселя на символ) — настоящих пикселей API модов не даёт. Кадр
  собирается в пиксельном буфере, поэтому движение идёт с шагом в полклетки. Чтобы перерисовать
  картинку, правится её карта; `npm run preview` показывает лист спрайтов и сцены. Стволы и
  другие вертикали шириной в 2 пикселя ставьте на чётные столбцы, иначе они рисуются двумя половинками.
- `hooks/dino.tsx` — поверхность (`Client`): таймер кадров, клавиши, мышь, вывод.
- `hooks/register.tsx` — хуки: команда `/dino`, рекорд в `$.store`, сигнал «Claude закончил».

## Разработка

```sh
npm test             # логика и кадры: node --test, без зависимостей (нужен node 24+)
npm run test:hooks   # хуки и поверхность в окружении движка: claude plugin test
npm run typecheck    # tsc; типы API кладёт /plugin-types в .claude/types
npm run preview      # характерные кадры в консоль, без Claude Code
```

В тесте логики есть бот: он проходит игру до потолка скорости на 15 сочетаниях ширины поля и
зерна случайности для каждого набора размеров — так проверяется, что физика прыжка, размеры
препятствий и зазоры проходимы. Отдельный тест сверяет размеры битовых карт с числами набора.
